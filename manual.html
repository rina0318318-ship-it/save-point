01
SAVE POINT とは
SAVE POINTは、毎日開きたくなるタスク管理ツールです。
普通のTODOアプリと違い、タスクを「クエスト」として捉え、完了するたびにゴールド（G）とEXPを獲得できます。
◆ SAVE POINTの考え方
「全部やらなければ」ではなく「今日も少し前進した」を積み重ねることを大切にしています。
完璧を目指すのではなく、毎日セーブポイントに立ち寄る習慣を作ることがゴールです。
スマホ・PCどちらでも使えます。データはブラウザに保存されるため、アカウント登録は不要です。
02
はじめかた
URLをブラウザで開けば、すぐに使えます。インストール不要です。
1
ブラウザでURLを開く
スマホのSafari・Chrome、またはPCのブラウザでアクセスします。
2
ホーム画面に追加する（推奨）
スマホの場合、ホーム画面に追加するとアプリのように使えます。
iPhone：Safariで開いて → 共有ボタン →「ホーム画面に追加」
Android：Chromeで開いて → メニュー →「ホーム画面に追加」
3
今日のクエストを追加して討伐する
「今日」タブで今日やることを入力して、完了したらタップするだけです。
◆ データについて
データはあなたのブラウザ（localStorage）に保存されます。
ブラウザのデータを削除すると、データもリセットされますのでご注意ください。
03
今日タブの使い方
毎日開く場所です。今日やることだけを集中して管理します。
📋
TODAY'S QUEST（今日やること）
最も重要なタスクを置く場所。金色のラインで強調されます。完了するとゴールドとEXPを多く獲得できます。
+15G / +30 EXP
🔄
日次収益クエスト
毎日繰り返す習慣タスク。出品・いいね回りなどのルーティンを置きます。毎日リセットされます。
+10G / +20 EXP
🏠
生活・運動
ゴミ出し・洗濯・運動などの生活タスク。小さくても積み重なります。
+5G / +10 EXP
+
クエストを追加する
画面下の入力欄にタスクを入力して「+」を押します。セクション（今日 / 日次 / 生活）を選んで追加できます。
✓
完了したらタップ
クエストをタップすると討伐完了。ゴールドと金粉エフェクトが出ます。
✕
不要なクエストを削除
各クエストの右端の「✕」で削除できます。入力ミスや不要になったものを消せます。
◆ チェックの仕組み
チェックは当日限り有効です。翌日になると自動的にリセットされ、新しい一日として始まります。
追加したクエストは削除しない限り翌日も残ります。
04
プロジェクトログ
数日〜数ヶ月かかる長期プロジェクトを管理する場所です。締切と進捗を見渡せます。
1
プロジェクトを追加する
プロジェクト名・開始日・締切を入力して「刻む」を押します。色が自動で割り当てられます。
2
進捗を更新する
+5% / +10% ボタンで進捗を記録します。途中の進捗ではEXPのみ獲得できます。
3
討伐完了で報酬獲得
「討伐完了」を押すと +100G +100 EXP を獲得できます。完了時のみゴールドが入ります。
◆ PCでの表示
PCで開くと2カラムのガントチャート表示に切り替わります。左に一覧、右に日単位のタイムラインが表示され、今日の位置が金色のラインで示されます。
05
月の誓い
数値では管理できない「今月どう在りたいか」を刻む場所です。KPI管理ではなく、意思や宣言を置くページです。
◆ 例えばこんな誓いを
・出品を止めない。毎日一つでも前に進む。
・撮影に丁寧に向き合う。
・朝を整える。開幕を大切にする。
・読書を始める。
1
誓いを入力して「刻む」
テキストを入力し、色を選んで刻みます。いつ刻んだかも記録されます。
2
「体現している」で記録
誓いを実践できていると感じたら「体現している」を押します。+5Gが入ります。
06
週PDCA
週単位で数値目標（KPI）を管理し、振り返りを記録する場所です。
PLAN — 今週の目標を設定
KPI名・目標値・単位を入力して週の目標を刻みます。（例：メルカリ売上 / 150000 / 円）
CHECK — 現在値を入力
現在の数値を入力すると達成率が自動計算されます。目標達成で +50G 獲得。
DO / ACT — 振り返りメモ
今週やったこと・来週に活かすことを自由に記録します。週をまたいでも保存されます。

絶好調
達成率80%以上。金色に輝きます。
状態

達成率50%以上。普通の状態。
状態

09
よくある質問
チェックしたタスクが翌日消えた
正常な動作です。チェック状態は毎日リセットされます。追加したクエスト自体は削除しない限り残ります。
ブラウザを変えたらデータが消えた
データはブラウザのlocalStorageに保存されています。別のブラウザや端末では引き継がれません。いつも同じブラウザで開くことをおすすめします。
固定クエスト（最初から入っているもの）を消したい
各クエストの右端の「✕」ボタンで削除できます。削除しても再読み込みで戻ることはありません。
精霊の契約にゴールドが足りない
まずクエストをいくつか完了してゴールドを貯めてください。ALL CLEARで+100Gが入るので、その後に契約できます。
他の人とデータを共有できる？
現在はできません。URLをシェアすれば同じアプリを使えますが、データはそれぞれのブラウザに独立して保存されます。
スマホとPCで同期できる？
現在はできません。データはブラウザに保存されるため、スマホとPCは別々のデータになります。メインで使うデバイスを1つ決めることをおすすめします。
